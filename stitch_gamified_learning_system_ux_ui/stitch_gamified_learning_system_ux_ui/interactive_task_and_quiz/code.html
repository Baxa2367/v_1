Мемоизация арқылы экспоненциалды рекурсияны оңтайландыру

translate Қазақша / Орысша нұсқасын көру (Тапсырманы аудару)

Фибоначчи сандарын табудың қарапайым O(2^n) экспоненциалды рекурсивті алгоритмі берілген. Неліктен n = 50 мәні үшін бұл алгоритм қайталанатын қосалқы есептердің салдарынан стектің толып кетуіне (stack overflow) әкелетінін анықтаңыз.

Бағытталған ациклдік графтың (DAG) fib(3) сияқты бірдей тармақтарды мыңдаған рет қайта есептейтініне назар аударыңыз. Шақырулар ағашын сызықтық тізбекке сығу үшін оңтайлы күй кэштеу стратегиясын таңдаңыз.

fibonacci_memo.py
Python 3.11
1 def fib(n, memo={}):
2     if n in memo: return memo[n] # ← Кэштен іздеу (Memo Cache Lookup)
3     if n <= 1: return n
4     memo[n] = fib(n-1, memo) + fib(n-2, memo)
5     return memo[n]
