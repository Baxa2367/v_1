Алғышарттарды тексеру

1.2-түйін (Рекурсия стегі) және 4.1-түйін сәтті аяқталды.

Жылдам құмсалғыш көрінісі Python 3.12
# Жоғарыдан-төмен мемоизация үлгісі
memo = {}
def fib(n):
if n in memo: return memo[n]
if n <= 1: return n
memo[n] = fib(n-1) + fib(n-2)
return memo[n]
Уақыт күрделілігі: O(N) Жад күрделілігі: O(N) стек
